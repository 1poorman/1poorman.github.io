## SAM3.1
{: width="800"}
![模型架构详图](/assets/img/model_diagram_SAM3.1.png)

### 1. 核心改进
SAM 3.1 于 2026 年 3 月发布，是 SAM 3 的重要升级版本，主要针对视频推理效率进行优化：

| 改进维度 | SAM 3 | SAM 3.1 |
| :------ | :--- | :--- |
| 多目标跟踪架构 | 逐对象独立处理内存 | **Object Multiplex** 共享内存联合处理 |
| 128 目标推理速度 | 基准性能 | **~7x 加速** |
| torch.compile 支持 | 基础优化 | 增强融合优化，减少内核启动开销 |
| 后处理策略 | 逐个对象处理 | 批量并行处理 |

### 2. Object Multiplex 技术
Object Multiplex 是 SAM 3.1 的核心创新，通过共享内存机制实现多目标的高效联合跟踪：

- **统一内存表示**：将多个目标的记忆状态编码到统一的张量中，避免重复计算
- **批量注意力计算**：在 Transformer 层中同时处理多个目标的查询，充分利用 GPU 并行计算能力
- **动态内存分配**：根据目标数量自适应调整内存大小，支持最多 128 个目标的实时跟踪
- **推理流程优化**：将原本需要 N 次独立推理的过程压缩到 1-2 次批量推理

### 3. 技术规格
- **参数量**：848M（与 SAM 3 保持一致）
- **视觉编码器**：450M 参数的 Perception Encoder
- **文本编码器**：300M 参数的 CLIP-based 编码器
- **精度支持**：bfloat16 / float16，配合 TF32 加速（Ampere 架构 GPU）
- **依赖环境**：Python ≥ 3.12，PyTorch ≥ 2.7，CUDA ≥ 12.6
- **推荐加速**：FlashAttention-3 + torch.compile

## SAM3
{: width="800"}
![模型架构详图](/assets/img/model_diagram_SAM3-.png)

SAM 3（Segment Anything with Concepts）是 Meta 于 2025 年 11 月发布的新一代通用分割模型，引入了开放词汇分割能力，支持通过自然语言描述分割 27 万种以上的概念类别。

### 1. 核心组件

| 核心组件 | 主要功能 | 关键创新点 |
| :------ | :--- | :--- |
| 感知编码器 (PE) |	多模态特征提取与融合，为后续模块提供统一的视觉-语言特征。包含视觉编码器、文本编码器和几何/实例编码器。| 	统一处理图像、文本和实例等多种输入，为下游任务提供对齐的特征。 |
| 检测器 (Detector)	 | 负责在图像中找到所有符合prompt的实例，输出其分割掩码和边界框。| 基于DETR架构；提出"Presence Head"，将识别与定位解耦，显著减少误报。|
| 跟踪器 (Tracker)	| 在视频中为每个实例维持稳定的身份（ID），实现跨帧追踪。| 继承了SAM 2的记忆机制，确保被跟踪对象在遮挡或暂离后仍能被准确匹配。|
|解耦设计 | 检测与跟踪任务分离，互不干扰，检测器专注目标检测，跟踪器则专门负责维持实例身份。| 避免了单模块同时处理两者导致的任务冲突，实现了1+1>2的效果。 |

### 2. 模块结构详情

#### 2.1 感知编码器 (Perception Encoder)
感知编码器是 SAM 3 的核心骨干网络，负责将多模态输入映射到统一的特征空间：

- **视觉编码器**：基于 ViT 架构，450M 参数，将输入图像转换为高分辨率特征图
- **文本编码器**：300M 参数，使用 CLIP 的文本编码器，将自然语言提示转换为语义嵌入
- **几何编码器**：处理点、框、掩码等空间提示，通过位置编码映射到特征空间
- **特征对齐机制**：通过对比学习确保视觉和语言特征在同一语义空间中对齐

#### 2.2 检测器 (Detector)
检测器基于 DETR (DEtection TRansformer) 架构，实现了从概念到实例的精确映射：

- **Presence Head 机制**：
  - 引入专用的"存在性检测头"，首先判断目标概念是否存在于场景中
  - 将识别（是否存在）与定位（在哪里）解耦，大幅降低误报率
  - 对于硬负样本（hard negatives）具有更强的判别能力
  
- **Promptable 分割**：
  - 支持文本、点、框、掩码、示例图像等多种提示方式
  - 通过交叉注意力机制融合提示特征与图像特征
  - 输出所有匹配实例的掩码和边界框（Exhaustive Instance Detection）

- **训练策略**：
  - 使用 400 万独特短语和 5200 万掩码的高质量人工标注数据
  - 结合 3800 万短语和 14 亿掩码的合成数据集
  - 创建了 SA-Co 基准测试，涵盖 124K 张图像和 1.7K 视频中的 214K 独特概念

#### 2.3 跟踪器 (Tracker)
跟踪器继承了 SAM 2 的密集记忆机制，实现视频中的稳定目标跟踪：

- **记忆机制**：
  - 维护帧间注意力记忆，存储历史帧的掩码和特征
  - 通过时间注意力实现跨帧特征匹配
  - 支持遮挡恢复和目标重新出现时的身份保持

- **会话式 API**：
  - 采用 Session-based 设计，支持有状态的交互式推理
  - 支持在任意帧添加/修改提示（文本、点、框）
  - 提供 propagate_in_video 接口将分割结果传播到全视频

#### 2.4 开放词汇分割 (Open-Vocabulary Segmentation)
SAM 3 最重要的突破是支持开放词汇分割：

- **概念理解能力**：不局限于预定义类别，可分割任意自然语言描述的目标
- **语义区分**：Presence Token 机制能区分语义相近的描述（如"白衣球员"与"红衣球员"）
- **零样本泛化**：在未见过的概念上仍能保持良好的分割性能
- **多实例检测**：当输入"car"时，自动检测并分割图像中所有车辆实例

### 3. 运行实例
- **视频追踪性能**：1280×720 视频，GPU 显存占用 5119 MiB used / 8310 MiB reserved (max: 7955 MiB used)，GTX 3090
- **支持提示类型**：text（精细描述）、point（支持正负样本）、box（边界框）、mask（掩码提示）
- **推理模式**：图像模式（批量处理）/ 视频模式（会话式交互）

### 4. SAM 3 Agent
SAM 3 Agent 将 MLLM（多模态大语言模型）与 SAM 3 结合，可处理复杂自然语言查询：

- **工作原理**：MLLM 作为"大脑"理解用户意图，分解复杂查询，指挥 SAM 3 执行分割
- **支持场景**：如"最左边穿蓝色背心的小孩"等需要空间推理和属性判断的复杂查询
- **后端支持**：可对接 Qwen-VL、GPT-4V 等多模大模型，或使用 vLLM 本地部署

## SAM2
{: width="800"}
![模型架构详图](/assets/img/model_diagram_SAM2.png)

SAM 2 由 Meta 于 2024 年发布，首次将分割能力从图像扩展到视频领域，实现了统一的图像和视频分割架构。

### 1. 核心技术

#### 1.1 统一架构设计
- **单模型多任务**：同一模型同时支持图像分割和视频目标跟踪
- **流式处理**：将视频视为帧序列流，支持实时逐帧处理
- **状态管理**：引入状态机管理跟踪过程，支持动态添加/修改提示

#### 1.2 记忆机制 (Memory Mechanism)
SAM 2 的记忆系统是其视频跟踪能力的核心：

- **记忆库 (Memory Bank)**：
  - 存储历史帧的掩码、特征和元数据
  - 采用 FIFO 策略管理记忆容量，保留关键帧
  - 支持记忆压缩以处理长视频
  
- **记忆注意力 (Memory Attention)**：
  - 通过交叉注意力查询记忆库中的相关信息
  - 时间位置编码确保时序一致性
  - 自适应记忆检索，优先关注近期和关键帧

- **记忆编码器 (Memory Encoder)**：
  - 将掩码和图像特征编码为紧凑的记忆表示
  - 多尺度编码保留细节和全局信息
  - 支持掩码条件的记忆过滤

#### 1.3 提示传播 (Prompt Propagation)
- **正向传播**：从提示帧向后续帧传播分割结果
- **双向传播**：支持从中间帧向前后双向传播
- **增量更新**：允许在任意时刻添加新提示并重新传播

#### 1.4 技术规格
- **图像编码器**：Hiera 架构，支持多尺度特征提取
- **模型变体**：sam2_hiera_tiny/small/base_plus/large 四种规格
- **实时性能**：在 RTX 4090 上可达 40+ FPS（640×640 分辨率）
- **训练数据**：基于 SA-1B 数据集，增加视频分割数据

### 2. 架构组件

| 组件 | 功能 | 技术细节 |
| :------ | :--- | :--- |
| 图像编码器 | 提取多尺度图像特征 | Hiera backbone，支持分层特征提取 |
| 提示编码器 | 编码点、框、掩码提示 | 位置编码 + 学习令牌，支持正负样本 |
| 记忆模块 | 维护跨帧状态 | 记忆库 + 记忆注意力 + 记忆编码器 |
| 掩码解码器 | 生成分割掩码 | Transformer 解码器，多尺度特征融合 |
| 后处理 | 优化输出质量 | 阈值过滤、连通性分析、掩码精炼 |

### 3. 应用场景
- **视频目标跟踪**：单次点击即可在整段视频中跟踪目标
- **交互式视频编辑**：实时修改提示，即时更新全视频分割
- **实时视频分析**：支持流式处理，适用于直播和实时监控

## SAM
{: width="800"}
![模型架构详图](/assets/img/model_diagram_SAM.png)

SAM (Segment Anything Model) 由 Meta AI 于 2023 年 4 月发布，是提示驱动分割的开创性工作，建立了史上最大分割数据集 SA-1B（1100 万张图像，11 亿个掩码）。

### 1. 核心架构

SAM 采用三模块协作系统：

#### 1.1 图像编码器 (Image Encoder)
- ** backbone**：ViT-H/16（Vision Transformer Huge），632M 参数
- **输入处理**：将图像缩放到 1024×1024，通过 16×16 patch 分割
- **输出特征**：64×64×256 的低分辨率密集特征图
- **预训练策略**：使用 MAE（Masked Autoencoder）在 SA-1B 上预训练
- **特性**：对微小物体敏感，支持任意分辨率输入（通过插值位置编码）

#### 1.2 提示编码器 (Prompt Encoder)
支持多种交互方式的提示编码：

- **点提示 (Points)**：
  - 前景点/背景点通过不同的位置编码区分
  - 每个点编码为 256 维向量
  - 支持多点组合提示
  
- **框提示 (Boxes)**：
  - 格式：[x1, y1, x2, y2]
  - 编码为左上和右下两个点提示的组合
  - 适用于快速粗略定位
  
- **掩码提示 (Masks)**：
  - 低分辨率掩码通过卷积下采样编码
  - 用于细化分割结果
  
- **文本提示**（SAM 2+/SAM 3 扩展）：
  - 通过 CLIP 文本编码器嵌入
  - 实现开放词汇理解

#### 1.3 掩码解码器 (Mask Decoder)
轻量级 Transformer 解码器：

- **特征融合**：通过多头自注意力和交叉注意力融合图像特征和提示特征
- **输出令牌**：
  - IoU 令牌：预测掩码质量分数
  - 掩码令牌：生成最终的二值掩码
  - 支持输出多个候选掩码（处理歧义性）
  
- **上采样**：通过转置卷积将 64×64 特征图上采样到 256×256，再插值到原始分辨率
- **掩码阈值**：默认 0.0 作为二值化阈值，可通过 confidence_threshold 调整

### 2. 关键技术

#### 2.1 数据引擎 (Data Engine)
SAM 的成功很大程度上归功于其创新的数据引擎：

- **辅助阶段 (Assisted-manual)**：
  -  annotator 使用 SAM 的早期版本辅助标注
  - 通过点/框提示快速生成掩码，人工修正
  
- **半自动阶段 (Semi-automatic)**：
  - 对未标注区域自动采样点网格
  - 运行模型生成候选掩码
  - 过滤低质量掩码，保留高置信度结果
  
- **全自动阶段 (Fully automatic)**：
  - 在规则网格上均匀采样点
  - 对每个点生成多个掩码（处理歧义性）
  - 通过 NMS 和掩码稳定性筛选高质量结果
  - 最终生成 11 亿个高质量掩码

#### 2.2 零样本泛化 (Zero-Shot Generalization)
- **提示工程**：通过变化提示类型、数量和位置优化分割结果
- **歧义处理**：对单个提示输出多个合理掩码，由用户选择
- **跨域性能**：在自然图像、医学影像、遥感图像等领域均表现优异

### 3. 技术规格

| 维度 | 规格 |
| :------ | :--- |
| 模型参数量 | 632M (ViT-Huge) |
| 输入分辨率 | 1024×1024（可调） |
| 输出分辨率 | 原始图像分辨率 |
| 特征维度 | 256 |
| 推理速度 | ~50ms/图像（RTX 3090） |
| 显存占用 | ~3.5GB（推理） |

### 4. 模型变体

| 模型 | Backbone | 参数量 | 适用场景 |
| :------ | :--- | :--- | :--- |
| vit_h | ViT-Huge | 632M | 最高精度 |
| vit_l | ViT-Large | 308M | 平衡性能 |
| vit_b | ViT-Base | 93M | 轻量部署 |

### 5. 局限性与挑战
- **纹理偏差**：对纹理特征过度敏感，可能忽略形状信息
- **提示不稳定**：对点提示位置敏感，微小偏移可能导致不同结果
- **小目标**：在极小物体（<10×10 像素）上表现下降
- **遮挡处理**：无法直接处理严重遮挡场景（SAM 2/3 改进）
