## SAM3
{: width="800"}
![模型架构详图](/assets/img/model_diagram_SAM3-.png)
### 1. 核心组件

| 核心组件 | 主要功能 | 关键创新点 |
| :------ | :--- | :--- |
| 感知编码器 (PE) |	多模态特征提取与融合，为后续模块提供统一的视觉-语言特征。包含视觉编码器、文本编码器和几何/实例编码器。| 	统一处理图像、文本和实例等多种输入，为下游任务提供对齐的特征。 |
| 检测器 (Detector)	 | 负责在图像中找到所有符合promt的实例，输出其分割掩码和边界框。| 基于DETR架构；提出"(Presence Head)"，将识别与定位解耦，显著减少误报。|
| 跟踪器 (Tracker)	| 在视频中为每个实例维持稳定的身份（ID），实现跨帧追踪。| 继承了SAM 2的记忆机制，确保被跟踪对象在遮挡或暂离后仍能被准确匹配。|
|解耦设计 | 检测与跟踪任务分离，互不干扰，检测器专注目标检测，跟踪器则专门负责维持实例身份。| 避免了单模块同时处理两者导致的任务冲突，实现了1+1>2的效果。 |

### 2. 模块结构详情

#### 2.1 视觉编码器（Image Encoder）
- **主干网络**：采用 ViT-Huge 架构，基于 DINOv2 风格的自监督预训练策略，在 ImageNet-22K 上进一步微调
- **特征提取**：将输入图像分割为固定大小的 patch，通过多层 Transformer 提取全局和局部特征
- **图像嵌入缓存**：提取的图像特征可缓存复用，支持多轮交互推理，提升效率

#### 2.2 多模态提示编码器（Multimodal Prompt Encoder）
- **文本提示**：通过轻量级 CLIP 文本编码器将自然语言转化为语义向量，支持 27 万+ 概念类别的开放词汇分割
- **几何提示**：沿用 SAM1 的稀疏提示编码方式，支持点（正/负样本）、边界框、掩码输入
- **图像示例**：利用 RoI Align 提取局部特征后投影至共享语义空间，支持视觉参考提示
- **语义对齐**：将多模态提示映射到与视觉特征对齐的嵌入空间，实现跨模态语义关联

#### 2.3 掩码解码器（Mask Decoder）
- **多层 Transformer 结构**：融合图像嵌入与提示向量，逐层细化掩码预测结果
- **语义注意力门控机制**：自动判断当前提示是否激活对应区域，提升分割精度
- **多候选输出**：输出多个候选掩码及其置信度评分，支持精细化边缘调整

#### 2.4 Presence Token 机制
- **概念区分能力**：能够区分语义相近的文本提示词（如"白衣球员"与"红衣球员"）
- **识别与定位解耦**：通过 Presence Head 将目标识别与空间定位分离，显著减少误报
- **开放词汇支持**：训练阶段引入大规模图文对齐数据集，建立语义概念与视觉特征的动态关联

### 3. SAM 3.1 关键升级

SAM 3.1 于 2026 年 3 月发布，核心改进集中在视频推理效率优化：

#### 3.1 Object Multiplex（对象多路复用）
- **共享内存架构**：采用共享内存方法实现联合多目标跟踪，彻底改变以往逐对象独立处理的低效模式
- **单次前向传播**：允许模型在单次前向传播中联合处理多个对象，128 个目标场景下推理速度提升约 **7 倍**
- **实时性能**：在不改变模型架构的前提下实现近实时推理能力

#### 3.2 技术优化
| 优化维度 | SAM 3 | SAM 3.1 |
| :--- | :--- | :--- |
| 多目标跟踪方式 | 逐对象独立处理 | Object Multiplex 联合处理 |
| 128 目标推理速度 | 基准性能 | **~7x 加速** |
| torch.compile 支持 | 基础编译优化 | 增强融合优化 |
| 后处理方式 | 逐个对象处理 | 批量并行处理 |
| 显存利用率 | 标准 | 显著提升，支持更多并发目标 |

## SAM2
{: width="800"}
![模型架构详图](/assets/img/model_diagram_SAM2.png)

### 1. 核心架构

SAM 2（Segment Anything 2）于 2024 年 7 月发布，将分割能力从图像扩展到视频领域，实现了统一的图像和视频分割框架。

#### 1.1 整体设计
- **统一架构**：同一模型同时支持图像分割和视频目标跟踪
- **流式处理**：支持视频帧的流式推理，无需等待完整视频加载
- **记忆机制**：引入跨帧记忆模块，实现长时序目标跟踪

#### 1.2 关键组件

| 组件 | 功能描述 | 技术特点 |
| :--- | :--- | :--- |
| 图像编码器 | 提取单帧图像特征 | 基于 ViT 架构，支持高分辨率输入 |
| 提示编码器 | 编码点、框、掩码等提示 | 与 SAM1 兼容，扩展视频场景 |
| 记忆注意力模块 | 融合历史帧信息 | 跨帧特征对齐与记忆检索 |
| 记忆编码器 | 编码和压缩历史帧特征 | 高效存储和检索长时序信息 |
| 记忆银行 | 存储历史帧的记忆特征 | 支持长时间跨度的目标跟踪 |

#### 1.3 记忆机制详解
- **记忆注意力（Memory Attention）**：在推理当前帧时，通过注意力机制检索和融合历史帧的相关特征
- **记忆编码（Memory Encoding）**：将当前帧的特征压缩并存储到记忆银行中
- **记忆融合**：采用多尺度特征融合策略，平衡短期和长期记忆
- **遮挡处理**：通过记忆回溯机制，在目标被遮挡后仍能准确恢复跟踪

#### 1.4 技术优势
- **零样本迁移**：无需针对特定视频数据集微调，直接应用于新场景
- **交互式推理**：支持在视频任意帧添加提示，实时传播到其他帧
- **高效推理**：图像嵌入可缓存，提示推理速度快
- **长视频支持**：记忆银行机制支持数百帧的连续跟踪

### 2. 与 SAM1 的主要区别

| 对比维度 | SAM1 | SAM2 |
| :--- | :--- | :--- |
| 支持模态 | 仅图像 | 图像 + 视频 |
| 时序处理 | 无 | 记忆机制支持跨帧跟踪 |
| 推理模式 | 单帧独立 | 流式连续推理 |
| 应用场景 | 静态分割 | 动态跟踪 + 静态分割 |
| 记忆模块 | 无 | 记忆银行 + 记忆注意力 |

## SAM
{: width="800"}
![模型架构详图](/assets/img/model_diagram_SAM.png)

### 1. 核心架构

SAM（Segment Anything Model）于 2023 年 4 月发布，首次将"基础模型"概念引入图像分割领域，构建了全新的任务定义、模型架构和大规模数据集。

#### 1.1 三位一体设计
SAM 的核心贡献在于解决了构建分割基础模型的三大难题：
- **任务定义**：提出"可提示分割"（Promptable Segmentation）新范式
- **模型架构**：设计通用的三模块架构，支持多种提示方式
- **训练数据**：构建 SA-1B 数据集，包含 1100 万张图像和 11 亿个掩码

#### 1.2 模型架构

SAM 采用经典的三模块设计：

**（1）图像编码器（Image Encoder）**
- **主干网络**：Vision Transformer (ViT)，支持 ViT-B、ViT-L、ViT-H 三种规格
- **预训练策略**：在 MAE（Masked Autoencoder）上预训练，学习丰富的视觉表征
- **输出特征**：将输入图像转换为 16×16 的图像嵌入（Image Embedding）
- **缓存机制**：图像嵌入可预先计算并缓存，支持高效的多轮交互

**（2）提示编码器（Prompt Encoder）**
- **稀疏提示**：点（points）和边界框（boxes），使用位置编码 + 学习嵌入
- **稠密提示**：掩码（masks），使用卷积提取特征并与图像嵌入逐元素相加
- **统一表示**：将不同类型的提示编码到相同的嵌入空间

**（3）掩码解码器（Mask Decoder）**
- **轻量级设计**：基于 Transformer 的双向交叉注意力机制
- **多尺度特征**：通过上采样和特征融合生成高分辨率掩码
- **多输出策略**：对每个提示输出 3 个候选掩码 + 1 个多提示掩码

#### 1.3 层次化输出机制

SAM 采用"Multiple Choice Learning"策略解决提示歧义性问题：

- **整体层次**：完整对象（如整个人、整辆车）
- **部分层次**：对象组件（如头部、车轮）
- **子部分层次**：更细粒度组件（如衬衫领口、轮毂）

对于每个提示，模型并行输出 **3 个掩码**对应这三个层次，并输出对应的置信度分数（预测的掩码-物体 IoU）。当提供多个提示时，使用第 **N+1** 个掩码处理非歧义情况。

#### 1.4 数据引擎（Data Engine）

SAM 采用三阶段数据引擎构建 SA-1B 数据集：

| 阶段 | 策略 | 数据规模 | 特点 |
| :--- | :--- | :--- | :--- |
| 阶段 1 | 辅助手动标注 | ~4.5M 掩码 | 标注员使用交互式工具标注 |
| 阶段 2 | 半自动标注 | ~5.9M 掩码 | 模型辅助发现新掩码，标注员审核 |
| 阶段 3 | 全自动标注 | ~1.1B 掩码 | 模型在大量无标注数据上自动生成掩码 |

#### 1.5 训练策略

- **损失函数**：采用 Focal Loss + Dice Loss 的组合作为分割损失
- **Minimum Loss 策略**：对多个输出掩码，选择与 GT IoU 最高的掩码计算损失
- **训练规模**：在 256 张 A100 GPU 上训练数周
- **模型规格**：
  - ViT-B: ~93M 参数
  - ViT-L: ~308M 参数
  - ViT-H: ~636M 参数

### 2. 技术特点

#### 2.1 零样本泛化能力
- **无需微调**：预训练模型可直接应用于新数据集和新任务
- **开放域支持**：不依赖预定义的类别体系
- **边界泛化**：在医学图像、卫星图像等分布外数据上表现良好

#### 2.2 交互式分割
- **实时响应**：图像嵌入缓存后，提示推理在毫秒级完成
- **多轮 refinement**：支持通过添加正负样本点逐步优化分割结果
- **灵活提示**：支持点、框、掩码及其组合

#### 2.3 性能指标

| 模型规格 | 参数量 | 图像分辨率 | 推理速度（GPU） | mIoU |
| :--- | :--- | :--- | :--- | :--- |
| ViT-B | 93M | 1024×1024 | ~48 FPS | 基准 |
| ViT-L | 308M | 1024×1024 | ~23 FPS | +2.1% |
| ViT-H | 636M | 1024×1024 | ~14 FPS | +3.5% |
