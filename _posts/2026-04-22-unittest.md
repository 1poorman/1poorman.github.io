# Unittest: python内置的单元测试框架

## 1. 基本结构
[测试用例（TestCase）]：继承 unittest.TestCase结构，包括具体的测试方法。
示例：
~~~
import unittest

 # 被测函数
def func(a, b):
    c=a*b
    return c

 # 测试用例
class TestMultiplication(unittest.TestCase):
    def test_func(self):
        self.assertEqual(func(1, 2), 3)  # 判断 1 + 2 = 3
        self.assertIn(str(func(3, 1)), '234')  # 判断 '3*1'字符串在'234'中

 # 运行测试
if __name__ == "__main__":
    unittest.main()
~~~

[测试套件（TestSuite）]：多个测试用例打包运行。
[测试运行器（TestRunner）]：用于执行测试并输出结果。
示例：
~~~

suite.addTest(TestModel('test_recognition'))

runner = unittest.TextTestRunner()
runner.run(suite)
~~~

## 2. 常见断言方法
   
assertEqual(a, b)：验证 a == b。
assertTrue(x)：验证 x 为 True。
assertFalse(x)：验证 x 为 False。
assertIsNone(x)：验证 x 为 None。
assertIsNotNone(x)：验证 x 非 None。
assertIn(a, b)：验证 a 在 b 中。
assertRaises(Error, func, *args)：验证函数 func 抛出指定异常。

## 3. 运行测试
   命令行：
   ~~~
   python -m unittest test_module.py
   ~~~
   代码内置
   ~~~
   if __name__ = "main":
        unittest.main()
   ~~~
